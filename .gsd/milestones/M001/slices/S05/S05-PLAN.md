# S05: Card Management

**Goal:** Parents can see all RFID card assignments at a glance and register new cards through a guided wizard
**Demo:** Card wall shows all cards with cover art, scan-and-select wizard registers a new card, edit/delete works

## Must-Haves

- Card wall displays all registered cards as grid with cover art and assigned content name
- Scan-and-select wizard guides: hold card to reader, pick content from library, confirm assignment
- User can edit an existing card's assigned content (folder, stream URL, or system command)
- User can delete a card assignment
- Card can be assigned to a folder, a stream URL, or a system command
