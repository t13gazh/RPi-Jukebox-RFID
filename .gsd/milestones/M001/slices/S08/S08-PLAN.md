# S08: Expert Settings

**Goal:** Advanced users can configure system, network, and hardware settings through the web UI instead of SSH
**Demo:** System info visible, WiFi configurable, GPIO/MPD settings editable, export/import works, debug logging toggleable

## Must-Haves

- Expert can view system info (IP, disk space, uptime) and trigger restart/shutdown
- Expert can configure WiFi settings from the browser
- Expert can configure GPIO pin assignments and MPD/audio settings
- Expert can export all settings and card configurations as a file, and import them on another box
- Expert can toggle debug logging and select UI language
