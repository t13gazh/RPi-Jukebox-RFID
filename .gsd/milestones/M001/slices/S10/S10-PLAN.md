# S10: Gyro Integration

**Goal:** Parents can configure the phonie-gyro tilt sensor through the web UI instead of editing config files
**Demo:** Web UI shows gyro config, sensitivity profiles selectable, calibration triggerable, gesture visualization works

## Must-Haves

- Web UI shows current gyro configuration and allows editing
- User can select from three sensitivity profiles
- User can trigger sensor calibration from the browser and see the result
- Gesture visualization shows which tilt direction triggers which action
