# S04: Library Browser

**Goal:** Parents can browse the music library visually and start playback directly from the browser
**Demo:** Library displays folders as cover art grid, grid/list switchable, search works, tapping item starts playback

## Must-Haves

- Library displays folders as a cover art grid with album/folder titles
- User can switch between grid view and list view
- User can search across the library and see results instantly
- User can sort by name or recently added, and filter by content type
- Tapping a library item starts playback and navigates to the player view
