# S07: Parent Settings

**Goal:** Parents can configure playback limits and behaviors that protect their children's listening experience
**Demo:** Max volume limit enforced, sleep timer works, startup volume configurable, audiobook resume position per card

## Must-Haves

- Parent can set a maximum volume limit that the box cannot exceed
- Parent can set a sleep timer (countdown) and a scheduled stop time
- Parent can configure startup volume, idle shutdown timer, and volume step size
- Parent can configure second-swipe RFID behavior (restart vs. resume)
- Audiobook resume position works per RFID card
