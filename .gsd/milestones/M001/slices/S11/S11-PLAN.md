# S11: PWA & Polish

**Goal:** The web UI works offline for local music, can be installed as a home screen app, and feels polished
**Demo:** Add-to-home-screen works fullscreen, app shell loads offline, Leichte Sprache UI text reviewed

## Must-Haves

- User can add the web UI to phone's home screen and it opens fullscreen like a native app
- Service Worker caches app shell so UI loads even without internet (local music still controllable)
- UI text follows "Leichte Sprache" principles: short sentences, common words, self-explanatory labels
