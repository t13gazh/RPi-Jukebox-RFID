# S09: Access Control

**Goal:** The web UI enforces three tiers of access so children see only the player and parents/experts must enter a PIN
**Demo:** Player accessible without auth, parent settings require PIN, expert settings require separate PIN, session persists across reloads

## Must-Haves

- Player view accessible without any authentication (open tier)
- Navigating to parent settings requires entering a 4-6 digit PIN
- Expert settings require a separate PIN (can differ from parent PIN)
- PIN session persists across page reloads but expires after configurable timeout
